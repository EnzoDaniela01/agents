3-Step Setup

Run these commands in your project root terminal.

STEP 1

Install .agents/

Automatically copies all 45 skills and 5 agent personas into your project root.

npm install https://github.com/EnzoDaniela01/agents.git --save-dev
STEP 2

Link Your AI IDE

Generate pointer files (.cursorrules and CLAUDE.md) so every AI assistant discovers your skills.

npx agents link
STEP 3

Keep Skills Updated

Pull the latest skills and prompt updates anytime from GitHub.

npx agents install --force

Install by Preset Bundle

Prefer a smaller footprint? Install only the bundle you need.

Core Engineering

Orchestrator, TDD, Poka-Yoke, Five-Axis Review, Change Tracker.

npx agents install --preset=core

UI & Design

UI/UX Pro Max, Tailwind/shadcn Styling, Design System, Brand, Slides.

npx agents install --preset=ui

QA & Debugging

Bug Hunter, Diagnosing Bugs, Performance Optimizer, Pre-Push Audit.

npx agents install --preset=qa

App & Architecture

API Endpoint Builder, API Design, Prototyping, Architecture Deepening.

npx agents install --preset=app
